Однако, если вы всё ещё видите ошибки "Undefined array key", это может происходить из-за того, что в некоторых версиях PHP (особенно 8+) предупреждения могут появляться даже при использовании isset(), или если код был изменён.

Чтобы полностью избежать таких предупреждений, рекомендую использовать оператор null coalescing (??), который предоставляет значение по умолчанию, если ключ не существует. Это более надёжный способ.

<?php

$score = 0;
$userAnswer1 = $_GET['userAnswer1'] ?? ''; 
if ($userAnswer1 == 'полный' || $userAnswer1 == 'Полный') {
    $score++;
}

$userAnswer2 = $_GET['userAnswer2'] ?? '';
if ($userAnswer2 == 'хуй' || $userAnswer2 == 'Хуй') {
    $score++;
}

$userAnswer3 = $_GET['userAnswer3'] ?? '';
if ($userAnswer3 == 'ни одного' || $userAnswer3 == 'Ни одного') {
    $score++;
}

echo 'Вы угадали ' . $score . ' загадок';

?>

Не вызывает предупреждений, даже если параметры GET не переданы.
Делает код чище и безопаснее.

Функция gues(player) — это основная функция игры "Угадайка" для двух игроков. Она обрабатывает попытку угадать число для конкретного игрока (1 или 2). Каждый игрок имеет своё случайное число (от 1 до 10), и у каждого есть до 3 попыток. Функция вызывается при нажатии кнопки "Ответить" для соответствующего игрока.

Общий алгоритм работы:
Получить ввод пользователя: Считать число, введённое игроком в поле ввода.
Определить цель и счётчик попыток: Выбрать правильное число и текущий счётчик попыток для данного игрока.
Увеличить счётчик попыток: Добавить 1 к количеству попыток игрока.
Проверить результат:
Если число угадано: Показать поздравление и скрыть элементы ввода.
Если попытки закончились: Показать проигрыш с правильным ответом и скрыть элементы.
Если число больше: Подсказать "Перебор".
Если число меньше: Подсказать "Недобор".
Обновить интерфейс: Изменить текст сообщения и скрыть поля, если игра окончена.
Теперь разберём логику каждой строки функции:


function gues(player) {
   // player — параметр (1 или 2), указывающий, для какого игрока вызвана функция.
   
   let userAnswer = readInt(player);
   // Вызвать вспомогательную функцию readInt(player), которая получает значение из поля ввода игрока (например, 'userAnswer1' для игрока 1).
   // Преобразовать строку в число с помощью parseInt и сохранить в переменную userAnswer.
   // Это введённое пользователем число для проверки.
   
   let answer = player === 1 ? answer1 : answer2;
   // Определить правильное число для данного игрока:
   // Если player === 1, то answer = answer1 (случайное число для игрока 1).
   // Иначе (player === 2), answer = answer2 (случайное число для игрока 2).
   // Тернарный оператор (? :) используется для условного выбора.
   
   let tryCount = player === 1 ? tryCount1 : tryCount2;
   // Получить текущий счётчик попыток для игрока:
   // Если player === 1, то tryCount = tryCount1.
   // Иначе, tryCount = tryCount2.
   // Это локальная копия счётчика, чтобы работать с ней.
   
   tryCount++;
   // Увеличить счётчик попыток на 1 (попытка засчитана).
   // Теперь tryCount отражает количество сделанных попыток для этого игрока.
   
   if (player === 1) tryCount1 = tryCount;
   else tryCount2 = tryCount;
   // Сохранить обновлённый счётчик обратно в глобальную переменную:
   // Если player === 1, обновить tryCount1.
   // Иначе, обновить tryCount2.
   // Это необходимо, потому что локальная переменная tryCount не влияет на глобальные счётчики между вызовами функции.
   
   if (userAnswer == answer) {
      // Проверить, угадано ли число (сравнение с двойным равенством, допускает нестрогое сравнение типов).
      // Если да:
      
      write(player, '<b>Поздравляю, Наконец то!</b>');
      // Вызвать функцию write(player, text), которая изменит текст в элементе 'info' + player (например, 'info1' для игрока 1).
      // Установить текст: "<b>Поздравляю, Наконец то!</b>" (поздравление с жирным шрифтом).
      
      hide('userAnswer' + player);
      // Вызвать функцию hide(id), которая установит display: 'none' для элемента с id 'userAnswer' + player (например, 'userAnswer1').
      // Скрыть поле ввода, так как игра окончена.
      
      hide('button' + player);
      // Скрыть кнопку "Ответить" для этого игрока (id 'button' + player).
      
   } else if (tryCount >= maxTryCount) {
      // Если число не угадано, проверить, исчерпаны ли попытки (tryCount >= 3).
      // maxTryCount = 3 — глобальная константа.
      // Если да (попытки закончились):
      
      write(player, 'Вы проиграли. <br>Правильный ответ ' + answer);
      // Изменить текст в 'info' + player на: "Вы проиграли. <br>Правильный ответ " + answer (показать правильное число).
      // <br> — тег для переноса строки.
      
      hide('userAnswer' + player);
      // Скрыть поле ввода.
      
      hide('button' + player);
      // Скрыть кнопку.
      
   } else if (userAnswer > answer) {
      // Если попытки не закончились и число не угадано, проверить, больше ли введённое число правильного.
      // Если да:
      
      write(player, 'Перебор. <b>Попробуйте ещё раз.</b>');
      // Изменить текст на подсказку: "Перебор. <b>Попробуйте ещё раз.</b>" (число слишком большое).
      
   } else if (userAnswer < answer) {
      // Если введённое число меньше правильного (и не равно, так как предыдущие условия не сработали):

      // Изменить текст на подсказку: "Недобор. <b>Попробуйте ещё раз.</b>" (число слишком маленькое).
      
   }
   // Конец функции. Если игра не окончена, игрок может ввести новое число и нажать кнопку снова.
}


Дополнительные замечания:
Глобальные переменные: Функция использует глобальные переменные answer1, answer2, tryCount1, tryCount2, maxTryCount, которые инициализируются вне функции.
Вспомогательные функции: readInt(player), write(player, text), hide(id) — помогают работать с DOM (документом HTML).
Логика игры: Игра продолжается до угадывания или исчерпания попыток. Каждый игрок играет независимо.
Возможные улучшения: Можно добавить валидацию ввода (например, проверку на число от 1 до 10) или сброс игры после окончания.
